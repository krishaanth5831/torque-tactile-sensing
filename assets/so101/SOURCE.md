# SO-101 model: source

`so101.xml`, `scene.xml` and `assets/*.stl` are copied unchanged from
[MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie) `robotstudio_so101`.
That model is derived from The Robot Studio's `so101_new_calib.xml`
([SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100)), and its zero pose matches
LeRobot's calibration middle pose. Only the meshes `so101.xml` references were copied.
